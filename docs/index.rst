Welcome to birdy's documentation!
=================================

**Birdy**: Birdy provides a command-line tool to work with Web Processing Services.

Need help?
^^^^^^^^^^

* If you encounter any errors or problems with `birdy`, please let us know! Open an issue at the `GitHub main repository <https://github.com/bird-house/birdy>`_.
* To be aware of changes in `birdy`, feel free to “watch” the GitHub repository. You can customize the watch function to notify you of new releases or more.
